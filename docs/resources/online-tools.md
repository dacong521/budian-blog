# 常用在线工具清单

这些是我隔三差五就会打开的站点，都不需要装软件。

## 查资料

| 站点 | 用来做什么 |
| --- | --- |
| [VitePress 文档](https://vitepress.dev) | 查配置项、主题写法，最权威 |
| [MDN](https://developer.mozilla.org/zh-CN/) | HTML / CSS / JS 的参考手册 |
| [Can I use](https://caniuse.com) | 查某个 CSS 属性各浏览器支持情况 |

## 写代码

| 站点 | 用来做什么 |
| --- | --- |
| [GitHub](https://github.com) | 放源码、看别人的实现 |
| [Vercel](https://vercel.com) | 静态站部署，推上去就自动构建 |
| [regex101](https://regex101.com) | 正则边写边看匹配结果 |

## 做图与临时处理

| 站点 | 用来做什么 |
| --- | --- |
| [Excalidraw](https://excalidraw.com) | 画流程图、架构图，手绘风格 |
| [Squoosh](https://squoosh.app) | 图片压缩，调质量看体积 |
| [Carbon](https://carbon.now.sh) | 把代码片段做成好看的图片 |

## 说明

清单会慢慢加。看到好用的就往这里补一条，顺便记一句「用来做什么」——过几个月回头看，最有用的是这句备注。
