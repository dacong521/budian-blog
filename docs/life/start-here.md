# 先开个博客，再想写什么

搭这个站之前，我在备忘录里存了十几条「想写的题目」，一条都没写完。

理由都差不多：标题不够好、开头不够顺、写着写着觉得没意思。后来想通了——卡住我的不是写作能力，是「必须写得像篇文章」这个念头。

所以这次先把壳搭起来。导航、首页、几篇示例，全弄好，然后坐在这儿等。等哪天有句话不吐不快，打开编辑器写两百字就发，不排版、不加图、不管结构。

空站比空白文档好一点：它至少提醒你，这里有个地方可以放东西。

写不出来的时候，就翻翻别人的博客。看完常常会发现，那些写得最好的文章，开头都很随意，像在跟朋友说话。

那就先这样。
